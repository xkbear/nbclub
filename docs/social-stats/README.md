# NewBee 社交数据看板：数据接入底座

状态：已实现本地可运行的私有看板和公众号官方只读采集器，代码见 [`apps/social-stats`](../../apps/social-stats/README.md)；尚未取得免费云主机、公众号 AppSecret 或白名单配置，未部署，也未显示真实数据。视频号仍待腾讯官方接口答复。

## 目标与账号

内部看板计划使用 `stats.new-bee.club`，按平台原始统计日期更新，并显示每项数据的来源、统计截止日和最近成功同步时间。首期只接入公众号与视频号的关注变化和内容表现；周报从已取得的日数据计算。小红书暂缓，不出现在首期看板，也不启动账号接入。

| 平台 | 账号显示名 | 自动数据源状态 |
| --- | --- | --- |
| 微信公众号 | 先蜂 AI 俱乐部 | 已核实为微信认证的企业服务号，基础调用凭据接口显示有权限；用户和图文统计接口的账号权限仍待实际只读调用验证 |
| 微信视频号 | 先蜂 AI 俱乐部 | 普通创作者号的关注及作品数据接口尚未核实；等待腾讯官方答复 |

账号显示名仅供界面使用。正式接入时另建稳定的内部 `account_key`，不可将同名账号混为一个账号。

## 与平台无关的数据契约

每次成功读取都转成一条[指标记录](metric-observation.schema.json)：平台、账号、统计对象（账号或内容）、指标、统计日期与时区、数值、数值含义、授权来源、采集时间和同步批次。连接器另输出[同步状态](connector-status.schema.json)。任何平台适配器只负责把已获授权的官方／合作方响应转换成这两个契约；展示层不读取平台凭证或原始登录态。

优先统一的账号指标是关注总数、当日新增、当日取消关注。若平台只提供每日总数，可计算相邻两天的**净变化**，不能将净变化冒充“新增关注”。公众号已实现的内容数据来自新版 `getbizsummary`，按内容发表日期归集，记录为 `publication_cohort_snapshot`；它可能随平台补算修订，不当成当日全部历史文章阅读量。内容指标保留平台本义：公众号阅读和视频号播放分别展示，不合并成一个未经定义的“曝光量”。点赞、评论、分享、收藏等只在数据源实际提供时显示。

每条指标通过 `(platform, account_key, subject.kind, subject.id, metric.key, stat_date, source.provider)` 去重；同一天平台修订数据时更新该记录并保留采集时间。历史回填也走相同契约。周报只使用已完成的统计日，不把尚未完成的一天视为零。

## 页面必须遵守的显示规则

- 未接入、未授权、接口未开放、同步失败分别显示明确状态；**缺失值显示“暂无数据”，绝不显示 0 或估算值**。
- 每张卡片同时显示指标名称、平台、统计截止日、来源及最近成功同步时间。同步失败时保留上一份真实数据，并标为“数据已过期”。
- 内容指标按各平台原始定义和统计日期显示。公众号阅读与视频号播放不能直接相加。
- 只有已验证的自动数据源可使状态变为“已连接”；后台可见、人工下载、营销介绍或第三方声称支持都不算接口验证。

## 接入与部署边界

- `new-bee.club` 当前由公开的 GitHub Pages 托管。账号数据、AppSecret、令牌、服务端密钥和私有 API 响应不得提交到本仓库或放进页面 JavaScript。
- 内部看板需要登录保护；采集任务与密钥保管在服务端。公众号 API 的固定出口 IP 在采集服务选定后，再交由公众号管理员添加白名单。不得为此重置现有密钥或改动消息服务器配置。
- 视频号仅接入平台明确授权、适用于普通创作者号的只读能力；不使用浏览器模拟、Cookie、抓包接口或绕过限制的第三方采集。小红书暂缓，数据契约仅预留未来扩展字段，不进行账号操作或自动采集。
- `stats.new-bee.club` 的 DNS 记录应在部署目标确定后一次性配置。当前仅有官网仓库写入权限，不等于域名或部署平台管理权限。

## 已核对的官方资料

- [腾讯云：公众号开放服务](https://cloud.tencent.com/document/product/1301/100187)列出 `getusercumulate`、`getusersummary`、`getarticlesummary`、`getarticletotal`、`getuserread` 和 `getusershare` 等接口；实际调用取决于账号权限。
- [腾讯广告：视频号助手资料](https://training.tencentads.com/uploads/202108/0rhYyjKh_vk9HWG.pdf)说明后台可查看和下载部分数据，但不构成普通创作者号 API 开放证明；[腾讯云新版 APIs 概述](https://cloud.tencent.com/document/product/1301/126222)也没有给出所需的普通创作者统计接口。

## 已收到的公众号后台证据

2026-09-29 的用户提供截图显示：该号是已认证的企业服务号；「基础信息」有 AppID、AppSecret 管理入口和 API IP 白名单入口；「接口管理 → 接口权限与额度 → 基础接口」中，获取接口调用凭据及稳定版调用凭据均显示「有权限」。另两张「接口监控」截图是调用趋势，不能证明用户分析或图文分析权限。「开放能力」页展示的订阅消息、语音识别和地理位置与本项目统计接口无关。

不再要求账号运营人员继续寻找或截取技术页面。待服务端、固定出口 IP 和密钥配置方式确定后，由开发侧进行一次官方只读统计接口调用，记录实际成功响应或权限错误，再决定可展示的指标。密钥由后台管理员通过安全渠道直接配置到服务端，不经聊天或公开仓库；先确认现有集成，再安排白名单设置，避免影响正在运行的系统。

账号运营人员随后反馈：目前没有已知的其他系统接入该服务号，也不知道 AppSecret 的含义或保管人。不要继续要求运营人员排查技术设置。开发侧先完成部署和密钥存放方案；如果届时确认旧密钥无法取得，由后台管理员在明确步骤下重置并当场安全保存新密钥。重置会使旧密钥失效，因此执行前仍需复核是否存在未被运营人员知晓的接入。

## 等待外部回复后的接入顺序

1. 公众号：选定带固定出口 IP 的服务端并确定密钥存放方式；后台管理员按一次性步骤完成密钥及白名单配置；以只读调用核对账号接口权限并读取一日真实数据验证字段，再启用每日任务。
2. 视频号：只在腾讯给出适用于普通创作者号的接口和授权路径后编写连接器。

这份契约可以用于直连或经正式授权的服务商。运行环境的当前建议与费用比较见[托管方案](hosting-decision.md)；应用已有可移植的部署包，但尚未开通或部署。公众号管理员的最终一次性步骤见[操作清单](admin-handoff.md)。
