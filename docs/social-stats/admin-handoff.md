# 给公众号管理员的一次性操作清单

给 DAVID 直接转发即可。现在先**不要操作**，等我们把服务器和测试地址准备好，再把实际公网 IP 填入下面空格后一次完成。当前截图已足够，不需要再找菜单或发更多截图。

## 你要做的事

1. 在电脑登录公众号后台，确认右上角是 **先蜂 AI 俱乐部**，然后进入之前截图中的 **「基础信息」**。不要进入手机「微信开发者助手」。
2. 在 **「开发密钥」** 一栏，看看团队是否已经安全保存了 AppSecret。它相当于这一个公众号交给程序使用的密码。**不要把它发到微信聊天，也不要截图。** 如果有，联系 Harry，由技术侧安排在服务器上直接输入即可，不用重置。
3. 如果确实找不到旧 AppSecret，由 DAVID 先核对一次：公众号目前有没有自动回复、第三方运营工具、网站登录或其他正在使用的系统。若确认没有，约一个 Harry 和技术侧同时在线的时间，再点 **AppSecret 旁的「重置」**。技术侧会负责把新密钥安全存到服务器；你不用研究服务器配置。重置会让旧密钥失效，所以这一步必须安排在服务器已经准备好时做。
4. 在同一页面的 **「API IP 白名单」** 旁点 **「设置名单」**，添加技术侧给出的实际公网 IP：`__________`。保存后把“已保存”告诉 Harry 即可。这里填的是一串数字和点，不是网址；其他原有地址保持原样。
5. 技术侧随后从服务器只读取一天公众号统计数据，验证权限。你不需要自己测试接口，也不需要操作消息推送、接口管理或视频号后台。

若页面要求管理员扫码或二次验证，由 DAVID 本人在官方后台完成。具体 IP 和录入密钥的服务器入口会在主机创建后由技术侧一次性补齐。任何人都不应在聊天中索要完整 AppSecret。
